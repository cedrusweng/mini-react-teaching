用最少的代码复刻 React 核心包之间的调用关系。点击按钮可观察一次完整更新链路。

核心调用链

  1. createElement / jsx → ReactElement
  2. createRoot → createContainer → createFiberRoot
  3. useState → dispatcher → renderWithHooks
  4. setState → scheduleUpdateOnFiber → Scheduler
  5. workLoop → beginWork / completeWork
  6. commitRoot → commitWork → HostConfig → DOM

事件系统从 DOM 节点找到 Fiber，再调用组件里的 onClick，最终汇入同一条更新链。
